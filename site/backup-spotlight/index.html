A browser for screen sharing · macOS

Keep your browser offstage.

Stage is a minimal Chromium browser for workshops, webinars and demos. The page fills the window, and your tabs appear only when you reach for them.

npx stage-browser https://example.com
or npm i -g stage-browser, then stage
What your audience sees

Everything above the page goes out on the call too.

Share an everyday browser window and the room sees your other tabs, your bookmarks and every badge that pops up. Share Stage and they see the page.

Run of show

Set the stage before you go live.

  1. Open your demo tabs from the terminal

    stage --size 1280x720 \ app.example.com docs.example.com

    Each address becomes a tab. --size fixes the window at 16:9, so nothing reflows when you start sharing.

  2. Share only the Stage window

    In Zoom, Meet or Teams, pick the Stage window instead of your whole screen. The audience sees the page, with no browser around it.

  3. Reach up when you need another tab

    Push the pointer against the top edge and the tabs slide in. Or stay on the keyboard: ⌘1 to ⌘9 switch tabs and ⌘L opens a page.

Features

Small on purpose.

Nothing above the page

No toolbar, address bar or bookmarks bar. Tabs float in a small capsule that slides over the page when you need it and leaves when you move away. ⇧⌘B pins it open.

Chrome extensions, Okta included

Add extensions from the Chrome Web Store. The Okta Browser Plugin installs from the Extensions menu, and its icon sits in the tab bar next to your tabs.

Starts from your terminal

stage <url> opens the page and hands your prompt back. Run it again and the new page joins the open window as a tab. There is no app bundle to sign or notarize.

Sized for the screen share

Window presets at 1280×720, 1440×900, 1600×900 and 1920×1080. Zoom with ⌘= and ⌘- so the back row can read. ⇧⌘O opens the current page in Google Chrome.

Shortcuts

Your hands stay on the keyboard.

⌘TNew tab, straight into the address box
⌘LGo to an address or search; suggests open tabs and history
⌘1to⌘9Jump to a tab (⌘9 is the last one)
⌃Tab⇧⌘]⇧⌘[Next or previous tab
⌘W⇧⌘TClose a tab, reopen the last closed one
⌘[⌘]Back and forward
⌘=⌘-⌘0Zoom in, zoom out, reset
⇧⌘BPin or unpin the tab bar
⌃⌘FFull screen
⇧⌘OOpen the current page in Google Chrome
Install

One command, no app to sign.

Try it with npx

npx stage-browser https://example.com

Nothing to install. Good for a first look.

Install the stage command

npm i -g stage-browser

Then open pages with stage example.com from any terminal.

Run from a clone

npm install && npm run cli:install

Links stage into ~/.local/bin so it follows your checkout.

Needs macOS and Node 18 or later. The first run downloads Chromium, about 100 MB.

Questions

Before your next session.

Does the Okta plugin work?

It installs from the Chrome Web Store, and its icon and pop-up appear in the tab bar. Stage supports most of the Chrome extension APIs, but not every one. If an extension misbehaves, press ⇧⌘O to open the page in Google Chrome.

Is it signed or notarized?

There is nothing to sign. Stage runs Electron's own Chromium build straight from your terminal, so there is no separate app bundle for macOS to check.

Why does the menu bar say "Electron"?

The bold app name in the macOS menu bar comes from the Electron binary that Stage runs. Share only the Stage window and the menu bar stays off the call.

Where are my logins and tabs kept?

In ~/Library/Application Support/Stage. An npx run, a global install and a clone all use the same profile, so you sign in once. Stage reopens your last tabs when it starts.

Does it run on Windows or Linux?

Not yet. Stage is macOS only.
