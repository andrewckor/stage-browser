Get started

Present the page,
keep your browser offstage.

Stage is a minimal Chromium browser for workshops, webinars and demos. The page fills the window, and your tabs appear only when you reach for them.

Runs from your terminal on macOS, with Chrome extensions, the Okta Browser Plugin included.

Nothing above the page

No toolbar, address bar or bookmarks. Tabs slide in from the top edge and leave when you move away.

Chrome extensions

Install from the Chrome Web Store. Okta's icon sits right in the tab bar.

Starts from the terminal

No app to build or sign. Run it again and the new page joins the open window as a tab.

$ npx stage-browser https://example.com
✔ opened 3 tabs
✔ session restored

How it works

Three steps before you go live.

Open your tabs

stage --size 1280x720 app.example.com docs.example.com opens each address as a tab in a fixed 16:9 window.

Share the Stage window

In Zoom, Meet or Teams, pick the Stage window instead of your whole screen. The audience sees the page, nothing else.

Reach up for tabs

Push the pointer to the top edge and the tabs slide in. Or use ⌘1–⌘9 and ⌘L.

Features

Small on purpose.

Pinned mode

⇧⌘B keeps the tab bar visible and moves the page below it.

Window presets

1280×720, 1440×900, 1600×900 and 1920×1080 from the View menu, or --size.

Readable from the back row

Zoom with ⌘= and ⌘-, reset with ⌘0.

Session restore

Stage reopens your last tabs, so a rehearsal setup is still there on the day.

Escape hatch

⇧⌘O opens the current page in Google Chrome.

App links

Zoom, Slack and Okta Verify links open in their own apps.

Shortcuts

⌘LGo to an address or search
⌘1–⌘9Jump to a tab (⌘9 is the last)
⌃Tab⇧⌘]⇧⌘[Next or previous tab

⌘[⌘]Back and forward

⇧⌘BPin or unpin the tab bar

Get started

Needs macOS and Node 18 or later. The first run downloads Chromium, about 100 MB.

# try it without installing
$ npx stage-browser https://example.com
# or install the stage command
$ npm i -g stage-browser
$ stage example.com docs.example.com

FAQ

Does the Okta plugin work?

Yes. It installs from the Chrome Web Store and its pop-up opens from the tab bar. Stage supports most Chrome extension APIs but not every one, so if an extension misbehaves, ⇧⌘O opens the page in Google Chrome.

Is it signed or notarized?

There's nothing to sign. Stage runs Electron's own Chromium build from your terminal, so there's no separate app bundle for macOS to check.

Why does the menu bar say "Electron"?

The bold app name comes from the Electron binary Stage runs. Share only the Stage window and the menu bar stays off the call.

Where are my logins and tabs kept?

In ~/Library/Application Support/Stage. npx, a global install and a clone all share it, so you sign in once.

Windows or Linux?

Not yet. Stage is macOS only.
