# Icon history

Earlier Stage app icons, kept for reference.

- `01-original-spotlight.*`: the first icon (a spotlight beam onto a window), used until the one-bit icon replaced it.
- `02-spotlight-candidate.svg`: the refined spotlight version (no lamp, sharp-to-soft beam, soft floor light), considered but not shipped.

The current icon is `../icon.svg` (with `icon.png` and `icon.icns` generated from it). Design rounds live in `../icon-options/`.
